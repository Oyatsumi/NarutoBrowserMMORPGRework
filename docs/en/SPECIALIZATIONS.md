# Specializations (Ninjutsu, Taijutsu, Genjutsu) and per-class Senjutsu

Portuguese version with all tables: [../ESPECIALIZACOES.md](../ESPECIALIZACOES.md).

- New ninjas start **without a specialization** (`users.charclass = 0`, "Student"); registration no longer asks for it.
  Students level up with the `1_*` columns of `levels` and only learn class-less jutsus.
- From level `control.classenivel` (default 5), in any village, the *Choose Specialization* icon opens `especializacao.php`
  (description, strengths/weaknesses, growth, exclusive jutsus and Senjutsu bonus of each class). Two steps: choose, then a
  confirmation page with a warning and an "I understand this choice is permanent" checkbox. **The choice is permanent**;
  only an admin can fix it in exceptional cases (edituser, logged in the audit log, no stat recalculation).
- On confirm, max HP/CH/TP, Strength, Dexterity and Attack/Defense Power get the difference between the new class and the
  `1_*` columns (levels 2..current) and the class's level jutsus up to the current level are learned.
- Class modifiers live in the `classes` table (Admin > Specializations): physical damage/crit (Taijutsu), elemental damage
  and elemental advantage (Ninjutsu, weakness: −5% physical defense), effect chance/duration/strength, chakra drain and
  effect resistance (Genjutsu, weakness: −3% jutsu damage); Taijutsu's weakness is weaker resistance to other players'
  effects. Applied in `funcoesjutsus.php` (`classemods()`), fight.php, `dueloacao()` (duels) and therefore pvp.php.
- All classes share one experience curve. 12 new exclusive jutsus (ids 56-67), generated by `tools/classes_especializacao.py`.
- Senjutsu: the bonus is no longer added to attackpower/defensepower; it is computed at combat time from the remaining NP
  (`senjutsuativo()`), so it disappears exactly when NP runs out, also for a duel opponent. Each class has its own bonus
  (`sj_*` columns); class-less ninjas keep +20% Attack/Defense.
- Balance simulation: `tests/classes_sim.py` (full before/after tables in the Portuguese document).
- Second balance pass (jutsu redistribution): some base jutsus are now taught at other levels per class (`MOVER` in the
  generator — e.g. Ninjutsu gets Ember Lance 24→32, Revitalization 45→52; Genjutsu gets Bitter Herb Touch 19→25, Cold Mist
  Veil 15→21, Revitalization 45→36; Taijutsu Battle Healing 11→9), a few exclusive jutsus were tuned (Rising Rock Pillar
  debuff 11%, Lightning Serpent 63 power, Wandering Ember Comet 260, Echo of the Slow Shadow 22, Labyrinth 18 CH) and three
  modifiers changed: Ninjutsu elemental advantage +25%→+65% (PvE only), Genjutsu physical damage +10%→+4% and physical
  defense +10%→0.
